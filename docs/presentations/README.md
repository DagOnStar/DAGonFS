# Presentations

| Deck | Audience | Length | Content |
| --- | --- | --- | --- |
| [DAGonFS-scientific-talk.pptx](DAGonFS-scientific-talk.pptx) | Workshop or conference | 20 min, 17 slides | Motivation, design (models, data plane, peer-to-peer threads), the 47-defect assessment, the evaluation against NFS and tmpfs with DAGonStar workflows, limitations, conclusions |
| [DAGonFS-tutorial.pptx](DAGonFS-tutorial.pptx) | Hands-on tutorial | 20 min, 17 slides | Compile, install, configure (CLI, `DAGonFS.ini`, launcher, Python API), test (ctest, mounted suite, workflow, Slurm) and evaluate (benchmark), each with its expected results |

Every slide has speaker notes with its time slot. The figures come from [`../../figures`](../../figures), and the numbers from [PERFORMANCE.md](../PERFORMANCE.md) and [TESTING.md](../TESTING.md) (Slurm jobs 19513–19516, November 2026). The charts are native PowerPoint charts, so their data can be edited in PowerPoint.

Both decks are generated by [`make_decks.js`](make_decks.js). Regenerate them when those documents change:

```bash
npm install pptxgenjs sharp
node docs/presentations/make_decks.js [path/to/apply_theme.js]
```

The optional argument is a module exporting `applyTheme(file, theme)`, which writes the deck's colours and fonts into the PowerPoint theme. Without it, slide colours fall back to Office's default theme palette (the chart colours are unaffected).
